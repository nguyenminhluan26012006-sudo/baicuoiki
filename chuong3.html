Chương 3: Câu lệnh điều kiện

3.1. Tổng quan về câu lệnh điều kiện

3.1.1. Vì sao cần câu lệnh điều kiện?

Trong các chương trước, chương trình của chúng ta luôn thực hiện tuần tự từ trên xuống dưới — mỗi câu lệnh đều được chạy đúng một lần, không có sự lựa chọn. Tuy nhiên, hầu hết bài toán thực tế đều yêu cầu chương trình phải rẽ nhánh: tùy vào dữ liệu đầu vào hoặc trạng thái mà thực hiện công việc khác nhau.

Ví dụ thực tế:

  • Nếu trời mưa → mang áo mưa; ngược lại → mặc áo thường.
  • Nếu điểm ≥ 5 → đỗ; ngược lại → trượt.
  • Nếu số dư tài khoản đủ → cho phép rút tiền; ngược lại → thông báo lỗi.

Câu lệnh điều kiện (conditional statement) cho phép chương trình:

  • Kiểm tra một biểu thức điều kiện (trả về true hoặc false).
  • Quyết định khối lệnh nào sẽ được thực thi dựa trên kết quả đó.

3.1.2. Các dạng câu lệnh điều kiện trong C++

C++ cung cấp các dạng câu lệnh điều kiện sau:

  1. if — dạng thiếu (chỉ xét khi điều kiện đúng)
  2. if … else — dạng đủ (xét cả hai trường hợp)
  3. if … else if … else — nhiều nhánh
  4. if lồng nhau (nested if)
  5. Toán tử điều kiện ba ngôi ? : (ternary operator)
  6. switch … case — so khớp với nhiều giá trị cụ thể

3.1.3. Vị trí của câu lệnh điều kiện trong chương trình

Câu lệnh điều kiện có thể xuất hiện ở bất kỳ đâu trong thân hàm — sau khi đã khai báo biến, và có thể lồng trong các câu lệnh điều kiện khác hoặc trong vòng lặp (sẽ học ở Chương 4).

    Khai báo biến
          ↓
    Nhập dữ liệu
          ↓
    Câu lệnh điều kiện  ← kiểm tra và rẽ nhánh
          ↓
    Xuất kết quả

3.2. Biểu thức điều kiện (biểu thức logic)

3.2.1. Khái niệm

Biểu thức điều kiện là biểu thức mà khi tính toán sẽ cho ra một trong hai giá trị: true (đúng) hoặc false (sai). Đây là kiểu dữ liệu bool trong C++ (đã học ở Chương 2).

Trong C++, true tương đương với giá trị số 1 (hoặc bất kỳ số khác 0), false tương đương với 0.

3.2.2. Các toán tử so sánh

Các toán tử này dùng để so sánh hai giá trị và trả về bool:

  • == — bằng (equal to)
  • != — khác (not equal to)
  • > — lớn hơn
  • < — nhỏ hơn
  • >= — lớn hơn hoặc bằng
  • <= — nhỏ hơn hoặc bằng

Ví dụ: Giả sử a = 5, b = 3:

  • a == b → false
  • a != b → true
  • a > b → true
  • a < b → false
  • a >= b → true
  • a <= b → false

Lưu ý cực kỳ quan trọng: Phân biệt = (gán) với == (so sánh). Đây là lỗi phổ biến nhất của người mới học C++.

int a = 5;       // Gán: a nhận giá trị 5
if (a == 5) {    // So sánh: a có bằng 5 không?
    // ...
}
// if (a = 5) là SAI — vừa gán vừa kiểm tra (luôn đúng)

3.2.3. Các toán tử logic

Dùng để kết hợp nhiều biểu thức điều kiện lại với nhau:

  • && — AND (VÀ): chỉ đúng khi cả hai cùng đúng
  • || — OR (HOẶC): chỉ sai khi cả hai cùng sai
  • ! — NOT (PHỦ ĐỊNH): đảo ngược giá trị true ↔ false

Bảng chân trị:

+-------+-------+-----------+----------+--------+
|   A   |   B   |  A && B   |  A || B  |  ! A   |
+-------+-------+-----------+----------+--------+
| true  | true  |   true    |   true   | false  |
| true  | false |   false   |   true   | false  |
| false | true  |   false   |   true   | true   |
| false | false |   false   |   false  | true   |
+-------+-------+-----------+----------+--------+

Ví dụ:

int tuoi = 20;
bool co_giay_phep = true;

if (tuoi >= 18 && co_giay_phep) {
    cout << "Duoc phep lai xe";
}

3.2.4. Thứ tự ưu tiên toán tử

Khi một biểu thức có nhiều toán tử, C++ tính theo thứ tự ưu tiên (từ cao xuống thấp):

  1. ! (phủ định)
  2. Các toán tử số học: *, /, %, sau đó +, -
  3. Các toán tử so sánh: <, <=, >, >=, sau đó ==, !=
  4. &&
  5. ||
  6. Phép gán =

Ví dụ: 5 > 3 && 2 < 1 được hiểu là (5 > 3) && (2 < 1) → true && false → false.

Khuyến nghị: Luôn dùng dấu ngoặc đơn () khi có từ 3 toán tử trở lên để tránh nhầm lẫn.

3.2.5. Giá trị "truthy" và "falsy" trong C++

Trong C++, khi dùng một giá trị không phải bool trong điều kiện:

  • 0 → false
  • Mọi số khác 0 → true
  • Con trỏ nullptr → false
  • Con trỏ khác nullptr → true
int x = 5;
if (x) {                 // tương đương if (x != 0)
    cout << "x khac 0";
}

if (!x) {                // tương đương if (x == 0)
    cout << "x bang 0";
}

3.3. Câu lệnh if — dạng thiếu

3.3.1. Cú pháp

if (điều_kiện) {
    // khối lệnh được thực hiện nếu điều_kiện đúng
}

Trong đó:

  • điều_kiện là một biểu thức logic (trả về true/false)
  • Cặp { } bao quanh khối lệnh cần thực hiện

3.3.2. Nguyên tắc hoạt động

  • Nếu điều kiện đúng (true) → thực hiện toàn bộ khối lệnh.
  • Nếu điều kiện sai (false) → bỏ qua khối lệnh, chương trình chạy tiếp câu lệnh phía sau if.

Sơ đồ khối:

       ┌─────────────────┐
       │   điều_kiện ?   │
       └────────┬────────┘
           Đúng │ Sai
                ▼
       ┌─────────────────┐
       │    khối lệnh    │
       └────────┬────────┘
                │
                ▼
            (tiếp theo)

3.3.3. Ví dụ

Ví dụ 1: Kiểm tra một số có dương không.

#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Nhap n: ";
    cin >> n;

    if (n > 0) {
        cout << n << " la so duong" << endl;
    }

    cout << "Ket thuc chuong trinh" << endl;
    return 0;
}

Ví dụ 2: Kiểm tra điểm đỗ (≥ 5).

float diem;
cout << "Nhap diem: ";
cin >> diem;

if (diem >= 5.0) {
    cout << "Ban da do!" << endl;
    cout << "Chuc mung!" << endl;
}

3.3.4. Lưu ý khi viết if dạng thiếu

  • Nếu khối lệnh chỉ có một câu lệnh duy nhất, có thể bỏ cặp { }:
if (n > 0) cout << "Duong";

Tuy nhiên, khuyến nghị luôn dùng { } để tránh lỗi khó phát hiện khi mở rộng code sau này.

  • Không đặt dấu ; ngay sau điều kiện if (rất dễ nhầm):
if (n > 0);                    // SAI — dấu ; biến if thành rỗng
{
    cout << "Duong";           // câu lệnh này LUÔN chạy
}

3.4. Câu lệnh if … else — dạng đủ

3.4.1. Cú pháp

if (điều_kiện) {
    // khối lệnh 1 — chạy khi điều_kiện ĐÚNG
} else {
    // khối lệnh 2 — chạy khi điều_kiện SAI
}

3.4.2. Nguyên tắc hoạt động

Luôn có đúng một trong hai khối lệnh được thực hiện — không thể cả hai, cũng không thể không có khối nào.

Sơ đồ khối:

            ┌─────────────────┐
            │   điều_kiện ?   │
            └────────┬────────┘
              Đúng   │   Sai
           ┌─────────┴─────────┐
           ▼                   ▼
      ┌─────────┐         ┌─────────┐
      │ khối 1  │         │ khối 2  │
      └────┬────┘         └────┬────┘
           └─────────┬─────────┘
                     ▼
                 (tiếp theo)

3.4.3. Ví dụ

Ví dụ 1: Kiểm tra số chẵn/lẻ.

#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Nhap n: ";
    cin >> n;

    if (n % 2 == 0) {
        cout << n << " la so chan" << endl;
    } else {
        cout << n << " la so le" << endl;
    }

    return 0;
}

Ví dụ 2: Tìm số lớn hơn trong hai số.

int a, b;
cout << "Nhap a, b: ";
cin >> a >> b;

if (a > b) {
    cout << "So lon hon la: " << a << endl;
} else {
    cout << "So lon hon la: " << b << endl;
}

Ví dụ 3: Kiểm tra số âm/không âm.

if (n >= 0) {
    cout << "n khong am" << endl;
} else {
    cout << "n la so am" << endl;
}

3.4.4. Biến thể viết gọn

Nếu mỗi nhánh chỉ có một câu lệnh duy nhất:

if (n % 2 == 0)
    cout << "Chan";
else
    cout << "Le";

3.5. Câu lệnh if … else if … else — nhiều nhánh

3.5.1. Cú pháp

Khi có từ 3 trường hợp trở lên cần xét, ta dùng else if:

if (điều_kiện_1) {
    // khối lệnh 1
} else if (điều_kiện_2) {
    // khối lệnh 2
} else if (điều_kiện_3) {
    // khối lệnh 3
} else {
    // khối lệnh mặc định
}

3.5.2. Nguyên tắc hoạt động

  • Các điều kiện được kiểm tra tuần tự từ trên xuống.
  • Khi gặp điều kiện đúng đầu tiên → thực hiện khối lệnh tương ứng và thoát khỏi toàn bộ cấu trúc if.
  • Nếu không điều kiện nào đúng → thực hiện khối else (nếu có).
  • Khối else là tùy chọn — có thể bỏ qua.

3.5.3. Ví dụ

Ví dụ 1: Xếp loại học lực.

#include <iostream>
using namespace std;

int main() {
    float diem;
    cout << "Nhap diem: ";
    cin >> diem;

    if (diem >= 9.0) {
        cout << "Xuat sac" << endl;
    } else if (diem >= 8.0) {
        cout << "Gioi" << endl;
    } else if (diem >= 6.5) {
        cout << "Kha" << endl;
    } else if (diem >= 5.0) {
        cout << "Trung binh" << endl;
    } else {
        cout << "Yeu" << endl;
    }

    return 0;
}

Phân tích: Ở ví dụ trên, không cần viết diem >= 8.0 && diem < 9.0 vì nếu đã đến nhánh else if (diem >= 8.0) thì chắc chắn diem < 9.0 (do nhánh trên đã sai).

Ví dụ 2: Xác định số dương/âm/không.

int n;
cin >> n;

if (n > 0) {
    cout << "So duong";
} else if (n < 0) {
    cout << "So am";
} else {
    cout << "Bang 0";
}

3.5.4. Quy tắc sắp xếp điều kiện

Nguyên tắc vàng: Điều kiện chặt (hẹp) hơn phải đặt trước, điều kiện lỏng (rộng) hơn đặt sau.

Ví dụ SAI:

// Kết quả không như mong đợi!
if (diem >= 5.0) {
    cout << "Trung binh tro len";
} else if (diem >= 9.0) {
    cout << "Xuat sac";     // KHÔNG BAO GIỜ chạy được!
}

Lý do: nếu diem = 9.5, điều kiện diem >= 5.0 đã đúng nên chương trình thoát khỏi if ngay, không xét nhánh xuất sắc.

3.5.5. So sánh với dùng điều kiện kết hợp

Có thể viết nhánh điều kiện bằng cách dùng && thay vì else if, nhưng cách này dài dòng hơn và dễ sai:

// Cách 1: Dùng else if (KHUYẾN NGHỊ)
if (diem >= 9.0) {
    // ...
} else if (diem >= 8.0) {
    // ...
}

// Cách 2: Dùng điều kiện kết hợp (dài, dễ nhầm)
if (diem >= 9.0) {
    // ...
} else if (diem >= 8.0 && diem < 9.0) {
    // ...
}

3.6. Câu lệnh if lồng nhau (Nested if)

3.6.1. Khái niệm

if lồng nhau là câu lệnh if (hoặc if…else, if…else if…else) được đặt bên trong một câu lệnh if khác. Kỹ thuật này dùng khi cần kiểm tra nhiều điều kiện phân cấp: chỉ khi điều kiện ngoài đúng mới xét đến điều kiện trong.

3.6.2. Cú pháp

if (điều_kiện_ngoài) {
    // khối lệnh ngoài
    
    if (điều_kiện_trong) {
        // khối lệnh trong
    } else {
        // ...
    }
} else {
    // ...
}

3.6.3. Ví dụ

Ví dụ 1: Kiểm tra một năm có phải năm nhuận không.

#include <iostream>
using namespace std;

int main() {
    int nam;
    cout << "Nhap nam: ";
    cin >> nam;

    if (nam % 4 == 0) {
        if (nam % 100 == 0) {
            if (nam % 400 == 0) {
                cout << "Nam nhuan" << endl;
            } else {
                cout << "Khong phai nam nhuan" << endl;
            }
        } else {
            cout << "Nam nhuan" << endl;
        }
    } else {
        cout << "Khong phai nam nhuan" << endl;
    }

    return 0;
}

Cách viết gọn hơn bằng điều kiện kết hợp:

if ((nam % 400 == 0) || (nam % 4 == 0 && nam % 100 != 0)) {
    cout << "Nam nhuan" << endl;
} else {
    cout << "Khong phai nam nhuan" << endl;
}

Ví dụ 2: Kiểm tra tam giác hợp lệ và xác định loại tam giác.

float a, b, c;
cin >> a >> b >> c;

if (a + b > c && b + c > a && a + c > b) {
    if (a == b && b == c) {
        cout << "Tam giac deu";
    } else if (a == b || b == c || a == c) {
        cout << "Tam giac can";
    } else {
        cout << "Tam giac thuong";
    }
} else {
    cout << "Khong phai 3 canh tam giac";
}

3.6.4. Cảnh báo về lồng if

  • Lồng quá nhiều tầng (từ 3 tầng trở lên) làm code khó đọc, khó bảo trì.
  • Nên dùng điều kiện kết hợp (&&, ||) nếu có thể.
  • Nếu buộc phải lồng nhiều, hãy tách thành hàm riêng.
  • Luôn thụt lề nhất quán (thường 4 dấu cách mỗi tầng) để dễ đọc.

3.7. Toán tử điều kiện ba ngôi

3.7.1. Cú pháp

Toán tử ? : (ternary operator) cho phép viết gọn if…else khi cả hai nhánh đều là biểu thức đơn giản:

biến = (điều_kiện) ? giá_trị_nếu_đúng : giá_trị_nếu_sai;

3.7.2. Ví dụ

Ví dụ 1: Tìm max của hai số.

int a = 5, b = 8;

// Cách 1: Dùng if…else
int max_val;
if (a > b) {
    max_val = a;
} else {
    max_val = b;
}

// Cách 2: Dùng toán tử ba ngôi (gọn hơn)
int max_val = (a > b) ? a : b;

Ví dụ 2: Kiểm tra chẵn/lẻ — in trực tiếp.

int n = 7;
cout << n << " la so " << ((n % 2 == 0) ? "chan" : "le") << endl;

Ví dụ 3: Trị tuyệt đối.

int x = -5;
int abs_x = (x >= 0) ? x : -x;    // abs_x = 5

3.7.3. Ưu và nhược điểm

Ưu điểm:

  • Viết gọn, đặc biệt hữu ích trong biểu thức (ví dụ trong cout).
  • Rõ ràng khi logic đơn giản.

Nhược điểm:

  • Khó đọc khi lồng nhiều tầng: (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c)
  • Không dùng được cho khối lệnh nhiều câu.
  • Không nên lạm dụng — ưu tiên if…else khi cần rõ ràng.

3.8. Câu lệnh switch … case

3.8.1. Khái niệm

switch … case dùng khi cần so sánh một biến với nhiều giá trị hằng số cụ thể. Đây là dạng thay thế cho chuỗi if…else if dài dòng khi mỗi nhánh kiểm tra cùng một biến với các giá trị khác nhau.

Khi nào dùng switch thay vì if?

  • Kiểm tra một biến duy nhất với nhiều giá trị rời rạc (ví dụ: 1, 2, 3, 4).
  • Giá trị so sánh phải là hằng số (số nguyên, ký tự, enum).
  • Không dùng được cho biểu thức phức tạp như x > 5 && x < 10.

3.8.2. Cú pháp

switch (biểu_thức) {
    case giá_trị_1:
        // khối lệnh 1
        break;
    case giá_trị_2:
        // khối lệnh 2
        break;
    // ...
    default:
        // khối lệnh mặc định (khi không case nào khớp)
        break;
}

3.8.3. Nguyên tắc hoạt động

  • Tính biểu_thức và so sánh với từng case từ trên xuống.
  • Khi khớp → thực hiện từ câu lệnh đó đến khi gặp break.
  • Nếu không khớp case nào → thực hiện default (nếu có).
  • break dùng để thoát khỏi switch. Nếu quên break, chương trình sẽ chạy tiếp các case sau (gọi là fall-through).

3.8.4. Ví dụ

Ví dụ 1: In tên thứ trong tuần.

#include <iostream>
using namespace std;

int main() {
    int thu;
    cout << "Nhap thu (2-8): ";
    cin >> thu;

    switch (thu) {
        case 2:
            cout << "Thu Hai" << endl;
            break;
        case 3:
            cout << "Thu Ba" << endl;
            break;
        case 4:
            cout << "Thu Tu" << endl;
            break;
        case 5:
            cout << "Thu Nam" << endl;
            break;
        case 6:
            cout << "Thu Sau" << endl;
            break;
        case 7:
            cout << "Thu Bay" << endl;
            break;
        case 8:
            cout << "Chu Nhat" << endl;
            break;
        default:
            cout << "Thu khong hop le" << endl;
            break;
    }

    return 0;
}

Ví dụ 2: Máy tính đơn giản với phép toán.

double a, b;
char phep;
cout << "Nhap a, phep toan, b: ";
cin >> a >> phep >> b;

switch (phep) {
    case '+':
        cout << "Ket qua: " << a + b << endl;
        break;
    case '-':
        cout << "Ket qua: " << a - b << endl;
        break;
    case '*':
        cout << "Ket qua: " << a * b << endl;
        break;
    case '/':
        if (b != 0) {
            cout << "Ket qua: " << a / b << endl;
        } else {
            cout << "Loi: chia cho 0" << endl;
        }
        break;
    default:
        cout << "Phep toan khong hop le" << endl;
        break;
}

3.8.5. Trường hợp "fall-through" có chủ đích

Khi nhiều case cần thực hiện cùng một khối lệnh, có thể bỏ break ở các case đầu:

int thang;
cin >> thang;

switch (thang) {
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        cout << "31 ngay" << endl;
        break;
    case 4: case 6: case 9: case 11:
        cout << "30 ngay" << endl;
        break;
    case 2:
        cout << "28 hoac 29 ngay" << endl;
        break;
    default:
        cout << "Thang khong hop le" << endl;
}

3.8.6. So sánh switch và if…else if

  • switch: gọn hơn khi có ≥ 4 nhánh so sánh cùng biến với hằng số. Hiệu năng có thể tốt hơn (trình biên dịch tối ưu bằng bảng nhảy).
  • if…else if: linh hoạt hơn — dùng được biểu thức phức tạp, so sánh khoảng giá trị, kiểu dữ liệu float, string.
  • Cả hai đều có ưu/nhược điểm — chọn theo tình huống cụ thể.

3.9. Các lỗi thường gặp

  • Dùng = thay vì == — lỗi kinh điển. if (a = 5) vừa gán vừa kiểm tra, luôn đúng. Cách sửa: dùng == để so sánh.
  • Đặt dấu ; ngay sau if — if (x > 0); khiến câu lệnh điều kiện trở thành rỗng, khối lệnh phía sau luôn chạy bất kể điều kiện.
  • Quên break trong switch — chương trình sẽ "rơi" sang case kế tiếp, gây kết quả sai.
  • Sắp xếp điều kiện sai thứ tự — điều kiện rộng đứng trước khiến nhánh chặt phía sau không bao giờ chạy.
  • Nhầm toán tử logic — viết x < 5 && x > 10 (không bao giờ đúng), hoặc dùng and/or thay vì &&/|| (Python-style).
  • Quên dấu ngoặc đơn sau if — if n > 0 là lỗi cú pháp. Phải là if (n > 0).
  • Dùng switch với biến không phải hằng số — case x: là sai, case phải là giá trị hằng như case 5:.
  • Quên thụt lề — code chạy được nhưng cực khó đọc và dễ sinh lỗi logic.
  • So sánh số thực với == — if (0.1 + 0.2 == 0.3) thường trả về false do sai số dấu phẩy động. Nên dùng fabs(a - b) < 1e-9.

3.10.2. Bài tập cơ bản

Bài 1: Viết chương trình nhập một số nguyên n. In ra "n la so duong" nếu n > 0, ngược lại in "n khong duong".

Bài 2: Viết chương trình nhập hai số a, b. In ra số lớn hơn.

Bài 3: Viết chương trình kiểm tra một số nguyên n là số chẵn hay số lẻ.

Bài 4: Viết chương trình nhập điểm trung bình (0 → 10) và xếp loại:

  • ≥ 8.0: Giỏi
  • 6.5 → < 8.0: Khá
  • 5.0 → < 6.5: Trung bình
  • < 5.0: Yếu

Bài 5: Viết chương trình nhập vào ba số a, b, c. In ra số lớn nhất và số nhỏ nhất.

3.10.3. Bài tập vận dụng

Bài 6 (Phương trình bậc nhất): Nhập a, b. Giải và biện luận phương trình ax + b = 0:

  • Nếu a = 0 và b = 0 → vô số nghiệm
  • Nếu a = 0 và b ≠ 0 → vô nghiệm
  • Nếu a ≠ 0 → nghiệm x = -b/a

Bài 7 (Tam giác): Nhập ba số a, b, c. Kiểm tra có tạo thành tam giác không. Nếu có, cho biết là tam giác đều, cân, vuông, hay thường.

Bài 8 (Năm nhuận): Nhập một năm, kiểm tra xem có phải năm nhuận không. Gợi ý: Năm nhuận nếu chia hết cho 400, hoặc chia hết cho 4 nhưng không chia hết cho 100.

Bài 9 (Tính tiền điện): Nhập số kWh tiêu thụ, tính tiền theo bậc thang:

  • 0 → 50 kWh: 1678 đ/kWh
  • 51 → 100 kWh: 1734 đ/kWh
  • 101 → 200 kWh: 2014 đ/kWh
  • 201 → 300 kWh: 2536 đ/kWh
  • 301 → 400 kWh: 2834 đ/kWh
  • > 400 kWh: 2927 đ/kWh

Bài 10 (Máy tính đơn giản): Nhập hai số a, b và một phép toán (+, -, *, /). Thực hiện phép tính tương ứng (dùng switch). Xử lý trường hợp chia cho 0.

Bài 11 (Kiểm tra ký tự): Nhập một ký tự. Cho biết ký tự đó là chữ cái in hoa, chữ cái in thường, chữ số, hay ký tự khác.

Bài 12 (Xếp loại BMI): Nhập cân nặng (kg) và chiều cao (m). Tính BMI = cân nặng / chiều cao². Xếp loại:

  • BMI < 18.5: Gầy
  • 18.5 → < 25: Bình thường
  • 25 → < 30: Thừa cân
  • ≥ 30: Béo phì

3.10.4. Bài tập nâng cao

Bài 13 (Tăng giây): Nhập giờ, phút, giây. Kiểm tra hợp lệ (giờ 0-23, phút 0-59, giây 0-59). Nếu hợp lệ, in ra giờ-phút-giây của 1 giây sau (xử lý trường hợp giây = 59, phút = 59, giờ = 23).

Bài 14 (Số ngày trong tháng): Nhập tháng và năm. Cho biết tháng đó có bao nhiêu ngày (xử lý đúng tháng 2 năm nhuận). Dùng switch … case.

Bài 15 (Phương trình bậc hai): Nhập a, b, c. Giải phương trình ax² + bx + c = 0, biện luận đầy đủ các trường hợp:

  • a = 0 → phương trình bậc nhất
  • Δ = b² - 4ac < 0 → vô nghiệm
  • Δ = 0 → nghiệm kép x = -b/(2a)
  • Δ > 0 → hai nghiệm phân biệt

Bài 16 (Oẳn tù tì): Nhập lựa chọn của 2 người chơi: 0 = Búa, 1 = Kéo, 2 = Bao. Xác định người thắng hoặc hòa.

Bài 5 — Tìm max, min của 3 số:

#include <iostream>
using namespace std;

int main() {
    double a, b, c;
    cout << "Nhap a, b, c: ";
    cin >> a >> b >> c;

    double max_val, min_val;

    // Tim max
    if (a >= b && a >= c) max_val = a;
    else if (b >= a && b >= c) max_val = b;
    else max_val = c;

    // Tim min
    if (a <= b && a <= c) min_val = a;
    else if (b <= a && b <= c) min_val = b;
    else min_val = c;

    cout << "Max = " << max_val << endl;
    cout << "Min = " << min_val << endl;

    return 0;
}

Bài 14 — Số ngày trong tháng:

#include <iostream>
using namespace std;

int main() {
    int thang, nam;
    cout << "Nhap thang, nam: ";
    cin >> thang >> nam;

    switch (thang) {
        case 1: case 3: case 5: case 7: case 8: case 10: case 12:
            cout << "Thang " << thang << " co 31 ngay" << endl;
            break;
        case 4: case 6: case 9: case 11:
            cout << "Thang " << thang << " co 30 ngay" << endl;
            break;
        case 2: {
            bool nhuan = (nam % 400 == 0) || (nam % 4 == 0 && nam % 100 != 0);
            cout << "Thang 2 nam " << nam
                 << " co " << (nhuan ? 29 : 28) << " ngay" << endl;
            break;
        }
        default:
            cout << "Thang khong hop le" << endl;
    }

}

3.12. Tóm tắt chương

  • Câu lệnh điều kiện giúp chương trình rẽ nhánh — quyết định làm gì tùy vào dữ liệu/trạng thái.
  • Biểu thức điều kiện trả về true/false. Dùng toán tử so sánh (==, !=, >, <, >=, <=) và toán tử logic (&&, ||, !).
  • Phân biệt = (gán) và == (so sánh) — đây là lỗi phổ biến nhất.
  • if: chỉ thực hiện khi điều kiện đúng.
  • if…else: hai nhánh, luôn có đúng một nhánh được chạy.
  • if…else if…else: nhiều nhánh, xét tuần tự, thoát ngay khi gặp nhánh đúng đầu tiên. Sắp xếp điều kiện chặt → lỏng.
  • Nested if: if lồng trong if — dùng cho điều kiện phân cấp, nhưng nên hạn chế.
  • Toán tử ba ngôi ? :: viết gọn if…else khi mỗi nhánh là một biểu thức đơn giản.
  • switch … case: so khớp một biến với nhiều hằng số cụ thể. Nhớ break sau mỗi case (trừ khi cố ý fall-through).
  • Luôn thụt lề đúng, dùng { } ngay cả khi khối lệnh chỉ có một câu.
