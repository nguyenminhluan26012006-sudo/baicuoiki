Chương 2: Biến và Kiểu dữ liệu trong C++

2.1. Biến (Variable)

2.1.1. Khái niệm

Biến là một vùng nhớ được đặt tên, dùng để lưu trữ dữ liệu trong quá trình chương trình hoạt động. Giá trị của biến có thể thay đổi trong suốt quá trình thực thi.

Mỗi biến trong C++ có:

  • Tên (identifier) — định danh để tham chiếu đến vùng nhớ
  • Kiểu dữ liệu (type) — quy định loại giá trị và kích thước bộ nhớ
  • Giá trị (value) — dữ liệu thực tế được lưu
  • Địa chỉ (address) — vị trí trong bộ nhớ (lấy bằng toán tử &)

2.1.2. Khai báo biến

Cú pháp tổng quát trong C++:

kieu_du_lieu ten_bien;               // Khai báo
kieu_du_lieu ten_bien = gia_tri;     // Khởi tạo
kieu_du_lieu ten_bien1, ten_bien2;   // Nhiều biến cùng kiểu

Ví dụ:

int tuoi;                  // Khai báo, chưa khởi tạo
int tuoi2 = 20;            // Khai báo + khởi tạo
double diem_tb = 8.5;
char ky_tu = 'A';
bool la_sinh_vien = true;
int a = 1, b = 2, c = 3;   // Nhiều biến cùng kiểu

Lưu ý: Trong C++, biến phải được khai báo trước khi sử dụng. Nếu không khởi tạo, biến cục bộ sẽ có giá trị rác (garbage value) — không xác định.

#include <iostream>
using namespace std;

int main() {
    int x;                          // Chưa khởi tạo — giá trị rác
    cout << "x = " << x << endl;    // Có thể in ra số bất kỳ!

    int y = 0;                      // Khởi tạo tường minh — an toàn
    cout << "y = " << y << endl;
    return 0;
}

2.1.3. Quy tắc đặt tên biến

Bắt buộc:

  • Chỉ chứa chữ cái (a-z, A-Z), chữ số (0-9) và dấu gạch dưới _
  • Không bắt đầu bằng chữ số
  • Không trùng với từ khóa của C++ (int, return, class, for, ...)
  • Không chứa khoảng trắng và ký tự đặc biệt (@, #, $, %, -, ., ...)
  • Phân biệt chữ hoa và chữ thường (case-sensitive): tuoi ≠ Tuoi

Khuyến nghị (quy ước cộng đồng):

  • Tên biến nên có ý nghĩa, mô tả đúng mục đích
  • Dùng snake_case cho biến thường: diem_trung_binh
  • Dùng PascalCase cho tên class/struct: SinhVien
  • Hằng số viết IN HOA: MAX_SIZE, PI
  • Tránh đặt tên biến trùng với hàm thư viện: size, count, swap, max, min...

Ví dụ hợp lệ và không hợp lệ:

  • tuoi — hợp lệ
  • _diem — hợp lệ (bắt đầu bằng _)
  • ho_ten_1 — hợp lệ
  • 1tuoi — không hợp lệ (bắt đầu bằng số)
  • ho ten — không hợp lệ (có khoảng trắng)
  • ho-ten — không hợp lệ (có dấu gạch ngang)
  • int — không hợp lệ (trùng từ khóa)

2.1.4. Phân loại biến theo phạm vi

a) Biến cục bộ (Local variable)

  • Khai báo bên trong hàm hoặc block { }
  • Chỉ tồn tại và truy cập được trong phạm vi khai báo
  • Tự động hủy khi ra khỏi block
#include <iostream>
using namespace std;

int main() {
    int x = 10;              // Biến cục bộ của main
    {
        int y = 20;          // Biến cục bộ trong block
        cout << x + y << endl;  // 30 — OK
    }
    // cout << y;            // LỖI: y không tồn tại ngoài block
    return 0;
}

b) Biến toàn cục (Global variable)

  • Khai báo bên ngoài tất cả các hàm
  • Truy cập được ở mọi nơi trong chương trình
  • Tồn tại đến khi chương trình kết thúc
#include <iostream>
using namespace std;

int dem = 0;                 // Biến toàn cục

void tang() {
    dem++;                   // Truy cập được biến toàn cục
}

int main() {
    tang();
    tang();
    cout << dem << endl;      // 2
    return 0;
}

c) Biến static

  • Biến static cục bộ giữ giá trị giữa các lần gọi hàm
  • Biến static toàn cục chỉ có phạm vi trong file hiện tại
#include <iostream>
using namespace std;

void counter() {
    static int count = 0;    // Chỉ khởi tạo 1 lần duy nhất
    count++;
    cout << "Lan goi thu " << count << endl;
}

int main() {
    counter();               // 1
    counter();               // 2
    counter();               // 3
    return 0;
}

2.1.5. Khởi tạo biến trong C++11

Từ C++11, có thêm cú pháp khởi tạo bằng dấu ngoặc nhọn { } (uniform initialization):

int a = 10;              // C-style
int b(10);               // Constructor-style
int c{10};               // Uniform initialization (C++11)
int d = {10};            // Kết hợp

// Ưu điểm: tránh "narrowing conversion"
int x{3.14};             // LỖI: không cho ép double sang int ngầm
int y = 3.14;            // OK: chỉ cảnh báo (hoặc mất dữ liệu)

2.2. Kiểu dữ liệu (Data Type)

2.2.1. Khái niệm

Kiểu dữ liệu xác định:

  • Loại giá trị mà biến có thể lưu trữ
  • Kích thước bộ nhớ cần cấp phát
  • Phạm vi giá trị
  • Các phép toán có thể thực hiện trên biến

2.2.2. Phân loại kiểu dữ liệu

Kiểu dữ liệu C++
├── Kiểu nguyên thủy (Primitive / Fundamental)
│   ├── Số nguyên   (short, int, long, long long)
│   ├── Số thực     (float, double, long double)
│   ├── Ký tự       (char, wchar_t, char16_t, char32_t)
│   ├── Logic       (bool)
│   └── Void        (void)
└── Kiểu dẫn xuất (Derived)
    ├── Con trỏ     (pointer)
    ├── Mảng        (array)
    ├── Tham chiếu  (reference)
    └── Hàm         (function)

2.2.3. Kiểu số nguyên (Integer)

C++ cung cấp nhiều kiểu số nguyên với kích thước và phạm vi khác nhau:

  • short — 2 byte — phạm vi: -32,768 → 32,767
  • int — 4 byte — phạm vi: -2,147,483,648 → 2,147,483,647
  • long — 4 hoặc 8 byte (tùy nền tảng)
  • long long — 8 byte — phạm vi: -9.2×1018 → 9.2×1018
  • unsigned (không dấu) — gấp đôi phạm vi dương, không có số âm
#include <iostream>
using namespace std;

int main() {
    int a = 100;
    int b = -25;
    long long c = 1000000000000LL;   // Hậu tố LL cho long long
    unsigned int d = 4000000000U;    // Hậu tố U cho unsigned

    cout << a << " " << b << " " << c << " " << d << endl;
    return 0;
}

Lưu ý về tràn số (overflow):

int x = 2147483647;    // INT_MAX
x = x + 1;             // Tràn số → thành -2147483648
cout << x << endl;

2.2.4. Kiểu số thực (Floating-point)

  • float — 4 byte — độ chính xác ~7 chữ số thập phân — hậu tố f
  • double — 8 byte — độ chính xác ~15 chữ số — mặc định
  • long double — 10/12/16 byte (tùy nền tảng) — độ chính xác cao nhất
#include <iostream>
using namespace std;

int main() {
    float f = 3.14f;              // Hậu tố f bắt buộc cho float
    double d = 3.14159265358979;
    long double ld = 3.14159265358979L;

    double khoa_hoc = 1.5e3;      // 1500.0 (ký pháp khoa học)

    cout << f << endl;
    cout << d << endl;
    cout << khoa_hoc << endl;
    return 0;
}

Lưu ý về sai số:

double a = 0.1;
double b = 0.2;
cout << (a + b) << endl;   // 0.30000000000000004 (không chính xác tuyệt đối!)

// So sánh số thực: dùng epsilon
#include <cmath>
if (fabs(a + b - 0.3) < 1e-9) {
    cout << "Bang nhau" << endl;
}

2.2.5. Kiểu ký tự (Character)

  • char — 1 byte — lưu một ký tự ASCII (hoặc số nguyên -128 → 127)
  • wchar_t — 2 hoặc 4 byte — ký tự rộng (Unicode)
  • char16_t / char32_t — C++11 — Unicode UTF-16/UTF-32
#include <iostream>
using namespace std;

int main() {
    char c = 'A';           // Dấu nháy đơn cho ký tự
    char newline = '\n';    // Ký tự đặc biệt (escape)
    char tab = '\t';

    cout << c << endl;      // A
    cout << (int)c << endl; // 65 — mã ASCII

    // char thực chất là số nguyên nhỏ
    char d = 'A' + 1;
    cout << d << endl;      // B
    return 0;
}

Bảng ký tự escape thông dụng:

  • \n — xuống dòng (newline)
  • \t — tab ngang
  • \\ — dấu gạch chéo ngược
  • \' — dấu nháy đơn
  • \" — dấu nháy kép
  • \0 — ký tự null (kết thúc chuỗi)

2.2.6. Kiểu logic (Boolean)

  • bool — 1 byte — chỉ có 2 giá trị: true hoặc false
  • Trong C++, true = 1, false = 0
  • Bất kỳ giá trị khác 0 khi chuyển sang bool đều thành true
#include <iostream>
using namespace std;

int main() {
    bool a = true;
    bool b = false;
    bool c = 10;      // true (khác 0)
    bool d = 0;       // false

    cout << a << " " << b << endl;   // 1 0
    cout << boolalpha;                // In "true"/"false"
    cout << a << " " << b << endl;   // true false
    return 0;
}

2.2.7. Kiểu void

  • void — "không có kiểu" — dùng cho hàm không trả về giá trị hoặc con trỏ void
void in_thong_bao() {
    cout << "Hello" << endl;
    // Không return giá trị
}

void* p = nullptr;    // Con trỏ void (trỏ tới bất kỳ kiểu nào)

2.2.8. Từ khóa auto (C++11)

Từ C++11, auto cho phép trình biên dịch tự suy luận kiểu từ giá trị khởi tạo:

auto x = 10;              // int
auto y = 3.14;            // double
auto z = 'A';             // char
auto s = "Hello";         // const char*
auto b = true;            // bool

// Hữu ích với kiểu phức tạp
auto so_lon = 10000000000LL;   // long long

Lưu ý: auto bắt buộc phải có giá trị khởi tạo:

auto x;          // LỖI: không suy luận được
auto y = 10;     // OK

2.2.9. Toán tử sizeof

sizeof trả về kích thước (tính bằng byte) của kiểu hoặc biến:

#include <iostream>
using namespace std;

int main() {
    cout << "sizeof(int)    = " << sizeof(int)    << " bytes" << endl;
    cout << "sizeof(double) = " << sizeof(double) << " bytes" << endl;
    cout << "sizeof(char)   = " << sizeof(char)   << " bytes" << endl;
    cout << "sizeof(bool)   = " << sizeof(bool)   << " bytes" << endl;

    int a = 100;
    cout << "sizeof(a)      = " << sizeof(a) << " bytes" << endl;
    return 0;
}

Kết quả tham khảo (trên hầu hết nền tảng 64-bit):

sizeof(int)    = 4 bytes
sizeof(double) = 8 bytes
sizeof(char)   = 1 bytes
sizeof(bool)   = 1 bytes
sizeof(a)      = 4 bytes

2.3. Hằng số (Constant)

2.3.1. Hằng số với const

Từ khóa const khai báo biến không thể thay đổi giá trị sau khi khởi tạo:

#include <iostream>
using namespace std;

int main() {
    const double PI = 3.14159;
    const int MAX_SIZE = 100;

    // PI = 3.14;   // LỖI: không thể gán lại
    cout << "PI = " << PI << endl;
    return 0;
}

Quy tắc: const bắt buộc phải được khởi tạo ngay khi khai báo:

const int x;        // LỖI
const int y = 10;   // OK

2.3.2. Hằng số với #define

Cách cũ (C-style) — dùng chỉ thị tiền xử lý:

#define PI 3.14159
#define MAX_SIZE 100

// Lưu ý: #define chỉ là "thay thế văn bản", không có kiểu dữ liệu

So sánh const và #define:

  • const — có kiểu dữ liệu, được kiểm tra bởi compiler, phạm vi rõ ràng
  • #define — không có kiểu, chỉ thay thế văn bản, dễ gây lỗi khó hiểu
  • Khuyến nghị: dùng const hoặc constexpr thay cho #define

2.3.3. constexpr (C++11)

constexpr khai báo hằng số tính được tại thời điểm biên dịch — tối ưu hiệu năng:

#include <iostream>
using namespace std;

constexpr int SQUARE(int x) {
    return x * x;
}

int main() {
    constexpr int PI_INT = 3;
    constexpr int area = SQUARE(5);    // Tính tại compile-time
    cout << "area = " << area << endl;  // 25
    return 0;
}

2.3.4. Literal (giá trị hằng viết trực tiếp)

  • Số nguyên: 42, 0xFF (hex), 0b1010 (nhị phân, C++14), 052 (bát phân)
  • Số thực: 3.14, 1.5e3, 3.14f
  • Ký tự: 'A', '\n'
  • Chuỗi: "Hello", "Xin chao\n"
  • Logic: true, false
  • Con trỏ null: nullptr (C++11)

2.4. Ép kiểu (Type Conversion)

2.4.1. Chuyển đổi ngầm định (Implicit)

Trình biên dịch tự chuyển từ kiểu nhỏ sang kiểu lớn hơn (không mất dữ liệu):

int    a = 5;
double b = a;         // int → double (tự động, an toàn)
double c = 3.9;
int    d = c;         // double → int (ngầm định, MẤT phần lẻ → 3)

char   e = 'A';
int    f = e;         // char → int (ASCII: 65)

Thứ tự chuyển đổi ngầm định:

bool → char → short → int → long → long long → float → double → long double
                  ↑
              unsigned (biến thể)

2.4.2. Chuyển đổi tường minh (Explicit / Casting)

a) C-style cast (cũ)

double x = 3.99;
int y = (int)x;       // 3

b) C++-style cast (khuyến nghị)

C++ cung cấp 4 toán tử ép kiểu an toàn hơn:

  • static_cast — ép kiểu thông thường (số ↔ số, con trỏ trong cùng hierarchy)
  • dynamic_cast — ép kiểu an toàn trong đa hình (kiểm tra runtime)
  • const_cast — bỏ tính const
  • reinterpret_cast — ép kiểu "thô" (bit pattern), nguy hiểm
#include <iostream>
using namespace std;

int main() {
    double x = 3.99;
    int y = static_cast<int>(x);       // 3
    cout << y << endl;

    int a = 65;
    char c = static_cast<char>(a);     // 'A'
    cout << c << endl;
    return 0;
}

2.4.3. Một số ví dụ về ép kiểu

#include <iostream>
using namespace std;

int main() {
    // Số nguyên → số thực
    int a = 10, b = 3;
    double c = a / b;                    // 3 (chia nguyên!)
    double d = (double)a / b;            // 3.3333
    double e = static_cast<double>(a) / b;

    cout << c << endl;    // 3
    cout << d << endl;    // 3.33333
    cout << e << endl;    // 3.33333

    // Ký tự ↔ số nguyên
    char ch = 'A';
    int ma = ch;                          // 65
    char tiep = static_cast<char>(ma + 1); // 'B'

    cout << ma << " " << tiep << endl;
    return 0;
}

Cảnh báo: Ép kiểu có thể gây mất dữ liệu:

double big = 1e20;
int    small = static_cast<int>(big);    // Kết quả không xác định!

long long large = 5000000000LL;
int       loss  = static_cast<int>(large);  // Tràn số!

2.5. Nhập / Xuất dữ liệu

2.5.1. Xuất dữ liệu với cout

#include <iostream>
using namespace std;

int main() {
    int tuoi = 20;
    double diem = 8.5;
    string ten = "Nguyen Van A";

    // Cách 1: nối bằng <<
    cout << "Ten: " << ten << ", Tuoi: " << tuoi << endl;

    // Cách 2: dùng \n (nhanh hơn endl)
    cout << "Diem: " << diem << "\n";

    // Định dạng số thực
    cout << fixed << setprecision(2);   // 2 chữ số sau dấu chấm
    cout << "Diem: " << diem << endl;   // 8.50
    return 0;
}

So sánh endl và \n:

  • endl — xuống dòng và xả bộ đệm (flush buffer) — chậm hơn
  • \n — chỉ xuống dòng — nhanh hơn, khuyến nghị dùng trong vòng lặp lớn

2.5.2. Nhập dữ liệu với cin

#include <iostream>
using namespace std;

int main() {
    int tuoi;
    double diem;
    char ky_tu;

    cout << "Nhap tuoi: ";
    cin >> tuoi;

    cout << "Nhap diem: ";
    cin >> diem;

    cout << "Nhap ky tu: ";
    cin >> ky_tu;

    cout << "Tuoi: " << tuoi << ", Diem: " << diem
         << ", Ky tu: " << ky_tu << endl;
    return 0;
}

Lưu ý: cin >> dừng đọc tại khoảng trắng đầu tiên → không đọc được chuỗi có dấu cách.

2.5.3. Đọc chuỗi với getline

#include <iostream>
#include <string>
using namespace std;

int main() {
    string ho_ten;

    cout << "Nhap ho ten: ";
    getline(cin, ho_ten);          // Đọc cả dòng, bao gồm dấu cách

    cout << "Xin chao " << ho_ten << "!" << endl;
    return 0;
}

2.5.4. Lỗi thường gặp khi trộn cin và getline

#include <iostream>
#include <string>
using namespace std;

int main() {
    int tuoi;
    string ho_ten;

    cout << "Nhap tuoi: ";
    cin >> tuoi;                    // Đọc số, để lại '\n' trong buffer

    cout << "Nhap ho ten: ";
    getline(cin, ho_ten);           // LỖI: đọc luôn '\n' còn sót → chuỗi rỗng!

    cout << "Ten: [" << ho_ten << "]" << endl;
    return 0;
}

Cách sửa: thêm cin.ignore() trước getline:

cin >> tuoi;
cin.ignore();                       // Bỏ qua ký tự '\n' còn sót
getline(cin, ho_ten);               // Bây giờ đọc đúng

2.6. Các lỗi thường gặp của người mới

  • Giá trị rác — khai báo biến không khởi tạo, sau đó dùng → kết quả không xác định. Cách sửa: luôn khởi tạo biến khi khai báo
  • Tràn số — gán giá trị vượt phạm vi kiểu (ví dụ int nhận 3 tỷ). Cách sửa: dùng long long hoặc kiểm tra phạm vi
  • Chia nguyên — int / int luôn ra int. Cách sửa: ép một vế sang double: (double)a / b
  • So sánh số thực — 0.1 + 0.2 == 0.3 là false. Cách sửa: so sánh với epsilon: fabs(a - b) < 1e-9
  • Dùng biến ngoài phạm vi — biến cục bộ không truy cập được ngoài block. Cách sửa: khai báo ở phạm vi rộng hơn nếu cần
  • getline sau cin >> — chuỗi bị rỗng do còn '\n' trong buffer. Cách sửa: thêm cin.ignore()
  • Quên hậu tố — float f = 3.14; gây cảnh báo (3.14 mặc định là double). Cách sửa: viết 3.14f
  • Nhầm = với == — if (x = 5) là gán, không phải so sánh
  • Trùng tên biến với hàm thư viện — int size = 10; có thể gây xung đột. Cách sửa: đổi tên khác

  • chieu_cao (double) — chiều cao (m)
  • can_nang (double) — cân nặng (kg)
  • la_sinh_vien (bool) — true/false

In ra theo mẫu:

Ho ten: ...
Tuoi: ...
Chieu cao: ... m
Can nang: ... kg
La sinh vien: ...

Bài 2: Viết chương trình in kích thước (byte) của các kiểu dữ liệu: char, short, int, long, long long, float, double, bool bằng toán tử sizeof.

Bài 3: Viết chương trình nhập vào bán kính hình tròn r, tính và in chu vi, diện tích. Dùng hằng số const double PI = 3.14159.

Bài 4: Nhập nhiệt độ C, chuyển sang Fahrenheit theo công thức F = C * 9/5 + 32. In kết quả với 2 chữ số thập phân (dùng fixed và setprecision).

Bài 5: Nhập cân nặng (kg) và chiều cao (m), tính chỉ số BMI = cân_nặng / (chiều_cao × chiều_cao). In kết quả với 2 chữ số thập phân.

Bài 6: Nhập vào một số nguyên có 3 chữ số (100–999). In ra chữ số hàng trăm, hàng chục, hàng đơn vị và tổng của chúng.

Bài 7: Cho hai biến a = 5, b = 10. Hoán đổi giá trị để a = 10, b = 5. Làm bằng 3 cách (biến trung gian, cộng-trừ, hoặc std::swap).

Bài 8: Viết chương trình nhập vào họ tên đầy đủ (có dấu cách) và tuổi. In ra câu: "Chao [ten], ban [tuoi] tuoi.". Nhớ dùng getline và cin.ignore() đúng chỗ.

Bài 9: Tìm và sửa lỗi trong đoạn code sau:

#include <iostream>
using namespace std;

int main() {
    const int MAX = 100;
    MAX = 200;

    int x;
    cout << x << endl;

    int 1abc = 5;

    double d = 3.14;
    int i = d;

    return 0;
}

Gợi ý: Có 4 lỗi — gán lại hằng MAX, dùng biến chưa khởi tạo x, tên biến bắt đầu bằng số 1abc, ép kiểu ngầm định gây cảnh báo int i = d.

Bài 10: Viết chương trình nhập vào một số giây nguyên t, chuyển sang dạng giờ:phút:giây. Ví dụ: t = 3661 → 1:1:1.

2.8. Tóm tắt chương

  • Biến là vùng nhớ có tên, kiểu dữ liệu và giá trị thay đổi được. Trong C++, biến phải khai báo trước khi dùng.
  • Quy tắc đặt tên: chữ, số, _; không bắt đầu bằng số; không trùng từ khóa; phân biệt hoa/thường.
  • Phân loại theo phạm vi: biến cục bộ (local), biến toàn cục (global), biến static.
  • Các kiểu dữ liệu cơ bản: int, long long, float, double, char, bool, void.
  • auto (C++11) — tự suy luận kiểu từ giá trị khởi tạo; sizeof — lấy kích thước kiểu/biến.
  • Hằng số: dùng const hoặc constexpr (khuyến nghị) thay cho #define.
  • Ép kiểu: ngầm định (compiler tự làm) và tường minh (static_cast<T> — an toàn hơn C-style cast).
  • Nhập/xuất: cout << để xuất, cin >> để nhập, getline(cin, s) để đọc cả dòng có dấu cách.
  • Lưu ý: luôn khởi tạo biến, cẩn thận chia nguyên, so sánh số thực bằng epsilon, và dùng cin.ignore() khi trộn cin >> với getline.
