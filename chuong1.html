Chương 1: Giới thiệu về C++

1.1. Tổng quan về ngôn ngữ lập trình C++

1.1.1. Lịch sử hình thành và phát triển

C++ được phát triển bởi Bjarne Stroustrup tại phòng thí nghiệm Bell Labs (AT&T) vào năm 1979, ban đầu với tên gọi "C with Classes" (C có thêm lớp). Đến năm 1983, ngôn ngữ chính thức được đổi tên thành C++.

Các cột mốc quan trọng:

  • C++98 (1998): Chuẩn hóa đầu tiên (ISO/IEC 14882)
  • C++03 (2003): Sửa lỗi, tinh chỉnh
  • C++11 (2011): Auto, lambda, smart pointer, nullptr, range-based for
  • C++14 (2014): Generic lambda, biến template
  • C++17 (2017): if constexpr, structured bindings, filesystem
  • C++20 (2020): Concepts, modules, coroutines, ranges
  • C++23 (2023): std::expected, std::print, module hóa nâng cao

1.1.2. C++ là gì?

C++ là ngôn ngữ lập trình đa mẫu (multi-paradigm), kết hợp nhiều phong cách lập trình khác nhau:

  • Lập trình hướng thủ tục (Procedural Programming)
  • Lập trình hướng đối tượng (Object-Oriented Programming - OOP)
  • Lập trình tổng quát (Generic Programming) thông qua template
  • Lập trình hàm (Functional Programming)

C++ được coi là ngôn ngữ "middle-level" — vừa có khả năng thao tác cấp thấp (quản lý bộ nhớ trực tiếp như C), vừa có các tính năng trừu tượng hóa cấp cao.

1.1.3. Đặc điểm nổi bật của C++

a) Hiệu năng cao (Performance)

  • Biên dịch xuống mã máy (machine code) → chạy rất nhanh
  • Không có garbage collector → kiểm soát tuyệt đối tài nguyên
  • Được sử dụng rộng rãi trong game engines (Unreal Engine), hệ điều hành, trình duyệt, ứng dụng tài chính, AI/ML (TensorFlow, PyTorch backend)

b) Kiểm soát bộ nhớ

  • Cho phép quản lý bộ nhớ trực tiếp qua con trỏ (pointer)
  • Cung cấp cả cấp phát tĩnh (stack) và động (heap)
  • Từ C++11 có smart pointer giúp giảm rò rỉ bộ nhớ

c) Hướng đối tượng mạnh mẽ

  • Đóng gói (Encapsulation)
  • Kế thừa (Inheritance)
  • Đa hình (Polymorphism)
  • Trừu tượng hóa (Abstraction)

d) Tính tương thích

  • Hỗ trợ hầu hết các nền tảng: Windows, Linux, macOS, embedded
  • Có thể liên kết với mã C (C interop)
  • Thư viện chuẩn phong phú (STL — Standard Template Library)

e) Biên dịch (Compiled language)

  • Mã nguồn → mã máy trước khi chạy → tăng tốc độ thực thi

1.1.4. Cấu trúc một chương trình C++

Một chương trình C++ điển hình gồm:

Chỉ thị tiền xử lý (#include)
      ↓
Khai báo using namespace (tùy chọn)
      ↓
Khai báo hàm / biến toàn cục
      ↓
Hàm main()  ← điểm bắt đầu thực thi

1.1.5. Ứng dụng của C++

  • Hệ điều hành: Windows, một phần macOS, Linux kernel (một phần), Chrome OS
  • Trình duyệt: Chrome (V8 engine), Firefox
  • Game engine: Unreal Engine, Unity (C++ core), Godot
  • Cơ sở dữ liệu: MySQL, MongoDB, PostgreSQL (một phần)
  • Tài chính: High-frequency trading systems
  • AI/ML: TensorFlow core, PyTorch core, OpenCV
  • Hệ thống nhúng (Embedded Systems), IoT, Robotics
  • Phần mềm đồ họa: Adobe Photoshop, AutoCAD, Blender

1.1.6. So sánh C++ với một số ngôn ngữ khác

  • Hiệu năng: C++ rất cao, C rất cao, Java cao, Python trung bình
  • Quản lý bộ nhớ: C++ thủ công / smart pointer, C thủ công, Java tự động (GC), Python tự động (GC)
  • Hướng đối tượng: C++ có (đa mẫu), C không, Java có, Python có
  • Đa nền tảng: cả 4 ngôn ngữ đều có
  • Đường cong học: C++ khó, C khó, Java trung bình, Python dễ

1.2. Cài đặt môi trường lập trình C++

Để viết và chạy chương trình C++, cần 2 thành phần chính:

  1. Trình biên dịch (Compiler) — chuyển mã C++ → mã máy
  2. Trình soạn thảo / IDE — viết mã nguồn

1.2.1. Các trình biên dịch phổ biến

  • GCC / g++ — Linux, macOS, Windows (MinGW). Phổ biến nhất, mã nguồn mở
  • Clang / clang++ — macOS (mặc định), Linux. Nhanh, thông báo lỗi tốt
  • MSVC — Windows. Đi kèm Visual Studio
  • MinGW-w64 — Windows. Bản GCC cho Windows

1.2.2. Cài đặt trên Windows

Cách 1: Sử dụng Visual Studio (khuyến nghị cho người mới)

  1. Truy cập: https://visualstudio.microsoft.com/downloads/
  2. Tải Visual Studio Community (miễn phí)
  3. Trong trình cài đặt, chọn workload "Desktop development with C++"
  4. Nhấn Install và chờ hoàn tất
  5. Mở Visual Studio → Create a new project → Console App (C++)

Cách 2: Sử dụng MinGW-w64 + VS Code

  1. Tải MinGW-w64 từ: https://www.mingw-w64.org/downloads/ (hoặc dùng MSYS2 — khuyến nghị vì dễ cập nhật)
  2. Cài đặt và thêm đường dẫn bin (ví dụ: C:\mingw64\bin) vào biến môi trường PATH
  3. Kiểm tra bằng lệnh:
g++ --version
  1. Tải Visual Studio Code: https://code.visualstudio.com/
  2. Cài extension C/C++ (Microsoft) và C/C++ Extension Pack
  3. Cài Code Runner (tùy chọn)

Cách 3: Sử dụng Dev-C++

  • Tải tại: https://www.bloodshed.net/
  • Đơn giản, phù hợp học sinh phổ thông
  • Nhược điểm: lỗi thời, không cập nhật chuẩn C++ mới

1.2.3. Cài đặt trên Linux (Ubuntu/Debian)

sudo apt update
sudo apt install build-essential
g++ --version

1.2.4. Cài đặt trên macOS

Bước 1: Cài Xcode Command Line Tools:

xcode-select --install

Bước 2: Kiểm tra:

clang++ --version

Hoặc cài g++ qua Homebrew:

brew install gcc

1.2.5. Biên dịch và chạy chương trình bằng dòng lệnh

Giả sử có file hello.cpp:

# Biên dịch (với chuẩn C++17)
g++ -std=c++17 hello.cpp -o hello

# Chạy trên Linux/macOS
./hello

# Chạy trên Windows
hello.exe

Giải thích các tùy chọn biên dịch:

  • -std=c++17: Dùng chuẩn C++17
  • -o hello: Đặt tên file thực thi là hello
  • -Wall: Hiển thị tất cả cảnh báo
  • -Wextra: Cảnh báo bổ sung
  • -g: Thêm thông tin debug
  • -O2: Tối ưu hóa code

Ví dụ lệnh đầy đủ:

g++ -std=c++17 -Wall -Wextra hello.cpp -o hello

1.2.6. Cài đặt trên IDE trực tuyến (không cần cài đặt)

Nếu không muốn cài đặt, có thể dùng các trình biên dịch online:

1.3. Viết chương trình đầu tiên — "Hello, World!"

1.3.1. Chương trình đầu tiên

Tạo file hello.cpp với nội dung sau:

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}

Kết quả khi chạy:

Hello, World!

1.3.2. Giải thích chi tiết từng dòng

Dòng 1: #include <iostream>

  • Đây là chỉ thị tiền xử lý (preprocessor directive)
  • Yêu cầu trình biên dịch "chèn" nội dung của thư viện iostream vào chương trình
  • iostream = Input/Output Stream — thư viện cung cấp các công cụ nhập/xuất dữ liệu
  • Chứa định nghĩa của cout, cin, cerr, endl...

Dòng 2: using namespace std;

  • std = standard — không gian tên chuẩn của C++
  • using namespace std; cho phép dùng trực tiếp cout thay vì std::cout
  • Lưu ý: Trong các dự án lớn, nên dùng std::cout để tránh xung đột tên
  • Cách viết an toàn hơn: using std::cout; using std::endl;

Dòng 4: int main() { ... }

  • main() là hàm đặc biệt — điểm bắt đầu thực thi của mọi chương trình C++
  • Mọi chương trình C++ bắt buộc phải có hàm main
  • int là kiểu trả về — trả về một số nguyên cho hệ điều hành
  • Cặp { } đánh dấu phần thân hàm

Dòng 5: cout << "Hello, World!" << endl;

  • cout = character output — luồng xuất chuẩn (màn hình)
  • << là toán tử chèn (insertion operator), đẩy dữ liệu vào luồng
  • "Hello, World!" là chuỗi ký tự (string literal), đặt trong dấu nháy kép
  • endl = end line — xuống dòng và xả bộ đệm (flush buffer)
  • ; kết thúc câu lệnh (bắt buộc trong C++)

Dòng 6: return 0;

  • Trả về 0 cho hệ điều hành — báo hiệu chương trình kết thúc thành công
  • Giá trị khác 0 biểu thị lỗi

1.3.3. Biên dịch và chạy

# Biên dịch
g++ hello.cpp -o hello

# Chạy
./hello        # Linux/macOS
hello.exe      # Windows

Hoặc với Visual Studio: nhấn Ctrl + F5 (Start Without Debugging).

1.3.4. Các cách viết tương đương

Có nhiều cách viết cùng một chương trình. Dưới đây là một số biến thể:

Biến thể 1: Không dùng using namespace

#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

Biến thể 2: Dùng \n thay cho endl

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!\n";
    return 0;
}

\n nhanh hơn endl vì không xả bộ đệm. Chỉ nên dùng endl khi thực sự cần flush.

Biến thể 3: Trả về không tường minh (C++ cho phép)

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    // Không cần return 0; — mặc định main trả về 0
}

Biến thể 4: Dùng printf của C

#include <cstdio>

int main() {
    printf("Hello, World!\n");
    return 0;
}

1.3.5. Chương trình mở rộng — Nhập và xuất dữ liệu

#include <iostream>
using namespace std;

int main() {
    string name;
    int age;
    
    cout << "Nhap ten cua ban: ";
    getline(cin, name);          // Đọc cả dòng (có dấu cách)
    
    cout << "Nhap tuoi: ";
    cin >> age;                  // Đọc một số nguyên
    
    cout << "\nXin chao " << name << "!" << endl;
    cout << "Ban " << age << " tuoi." << endl;
    
    return 0;
}

Kết quả mẫu:

Nhap ten cua ban: Nguyen Van A
Nhap tuoi: 20

Xin chao Nguyen Van A!
Ban 20 tuoi.

Giải thích thêm:

  • cin >> là toán tử trích xuất (extraction), đọc dữ liệu từ bàn phím
  • getline(cin, name) đọc toàn bộ dòng, bao gồm cả dấu cách (khác với cin >> chỉ đọc đến khoảng trắng đầu tiên)
  • Lỗi thường gặp: Khi dùng lẫn cin >> và getline(), cần cin.ignore() để xóa ký tự \n còn sót lại

1.3.6. Cấu trúc cơ bản của một chương trình C++

+-------------------------------------+
|  #include <thư viện>                |  <- Chỉ thị tiền xử lý
+-------------------------------------+
|  Khai báo using namespace           |  <- (tùy chọn)
+-------------------------------------+
|  Khai báo biến/hằng toàn cục        |  <- (tùy chọn)
+-------------------------------------+
|  Khai báo/hiện thực các hàm khác    |  <- (tùy chọn)
+-------------------------------------+
|  int main() {                       |  <- Điểm bắt đầu
|      // Các câu lệnh                |
|      return 0;                      |
|  }                                  |
+-------------------------------------+

1.4. Các lỗi thường gặp của người mới

  • iostream: No such file or directory — Sai tên thư viện. Cách sửa: dùng #include <iostream> (không có .h)
  • cout was not declared — Thiếu #include <iostream> hoặc using namespace std;
  • expected ';' — Thiếu dấu chấm phẩy cuối câu lệnh. Thêm ;
  • undefined reference to 'main' — Không có hàm main. Thêm int main() { ... }
  • permission denied (Linux) — Chưa cấp quyền thực thi. Dùng chmod +x hello
  • Phím tắt chạy không hoạt động — Chưa cài compiler. Kiểm tra g++ --version

1.6. Tóm tắt chương

  • C++ là ngôn ngữ lập trình đa mẫu, hiệu năng cao, được phát triển từ năm 1979 bởi Bjarne Stroustrup.
  • C++ kết hợp lập trình hướng thủ tục, hướng đối tượng, tổng quát và hàm.
  • Để lập trình C++, cần compiler (g++, clang++, MSVC) và editor/IDE (VS Code, Visual Studio, Dev-C++...).
  • Chương trình C++ cơ bản cần: #include <iostream>, hàm int main(), và các câu lệnh kết thúc bằng ;.
  • cout << để xuất dữ liệu, cin >> để nhập dữ liệu, endl hoặc \n để xuống dòng.
  • Mọi chương trình C++ phải có duy nhất một hàm main() — điểm bắt đầu thực thi.
