Chương 6: Mảng và Chuỗi trong C++

6.1. Tổng quan về mảng

6.1.1. Vì sao cần mảng?

Giả sử bạn cần lưu điểm của 30 sinh viên. Nếu dùng biến thường, bạn phải khai báo:

double diem1, diem2, diem3, ..., diem30;

Cách này có nhiều bất tiện:

  • Cồng kềnh: khai báo hàng chục, hàng trăm biến riêng lẻ.
  • Không linh hoạt: không thể dùng vòng lặp để duyệt 30 biến đó.
  • Không mở rộng được: nếu cần 100 hay 1000 sinh viên thì không thể viết tay.
  • Không truyền được vào hàm một cách gọn gàng.

Mảng (array) ra đời để giải quyết những vấn đề trên. Mảng cho phép gom nhiều phần tử cùng kiểu vào một tên duy nhất, truy cập thông qua chỉ số, và dễ dàng duyệt bằng vòng lặp.

double diem[30];      // Một mảng 30 số thực — gọn hơn nhiều!

for (int i = 0; i < 30; i++) {
    cin >> diem[i];   // Duyệt bằng vòng lặp
}

6.1.2. Khái niệm mảng

Mảng là một tập hợp các phần tử có cùng kiểu dữ liệu, được lưu trữ liên tiếp trong bộ nhớ, và truy cập thông qua chỉ số (index).

Đặc điểm quan trọng:

  • Các phần tử có cùng kiểu dữ liệu.
  • Các phần tử được lưu liên tiếp trong bộ nhớ.
  • Chỉ số mảng trong C++ bắt đầu từ 0.
  • Kích thước mảng là cố định sau khi khai báo (với mảng tĩnh).

6.1.3. Phân loại mảng

  • Mảng một chiều (1D array): danh sách các phần tử.
  • Mảng hai chiều (2D array): bảng dữ liệu dạng hàng × cột (ma trận).
  • Mảng nhiều chiều (nD array): hiếm dùng, thường chỉ đến 3 chiều.

6.1.4. Vị trí của mảng trong chương trình

Mảng thường được khai báo trong main() hoặc trong hàm, sau đó được truyền vào các hàm khác để xử lý:

    #include ...
    using namespace std;

    void nhapMang(int a[], int &n);
    void xuatMang(int a[], int n);

    int main() {
        int a[100], n;
        nhapMang(a, n);
        xuatMang(a, n);
        return 0;
    }

    void nhapMang(int a[], int &n) { ... }
    void xuatMang(int a[], int n) { ... }

6.2. Mảng một chiều

6.2.1. Cú pháp khai báo

kieu_du_lieu ten_mang[kich_thuoc];

Trong đó:

  • kieu_du_lieu: kiểu của từng phần tử (int, double, char, bool, …)
  • ten_mang: tên mảng, đặt theo quy tắc định danh
  • kich_thuoc: số phần tử, phải là hằng số nguyên dương (literal hoặc const)

Ví dụ:

int a[5];           // Mảng 5 số nguyên
double diem[30];    // Mảng 30 số thực
char ten[50];       // Mảng 50 ký tự
bool co[10];        // Mảng 10 giá trị logic

const int MAX = 100;
int b[MAX];         // Hợp lệ — MAX là hằng số

Lưu ý: Kích thước mảng không được là biến thường:

int n = 10;
int a[n];           // KHÔNG chuẩn C++ (một số compiler cho phép nhưng không nên dùng)

6.2.2. Khởi tạo mảng

Cách 1 — Khởi tạo đầy đủ:

int a[5] = {1, 2, 3, 4, 5};

Cách 2 — Khởi tạo một phần (các phần tử còn lại = 0):

int a[5] = {1, 2};      // a = {1, 2, 0, 0, 0}

Cách 3 — Khởi tạo tất cả bằng 0:

int a[5] = {0};         // a = {0, 0, 0, 0, 0}

Cách 4 — Không chỉ định kích thước (trình biên dịch tự đếm):

int a[] = {10, 20, 30, 40};   // Kích thước = 4

Cách 5 — Khởi tạo bằng danh sách (C++11 trở lên):

int a[5] {1, 2, 3, 4, 5};

Lưu ý quan trọng:

  • Không được gán trực tiếp a = b cho hai mảng — phải sao chép từng phần tử.
  • Nếu khai báo mảng không khởi tạo (như int a[5];), các phần tử có giá trị rác (không xác định).

6.2.3. Truy cập phần tử

Cú pháp: ten_mang[chi_so]; — với chi_so từ 0 đến kich_thuoc - 1.

#include <iostream>
using namespace std;

int main() {
    int a[5] = {10, 20, 30, 40, 50};

    cout << a[0] << endl;   // 10
    cout << a[4] << endl;   // 50
    cout << a[2] << endl;   // 30

    a[1] = 99;              // Gán giá trị mới
    cout << a[1] << endl;   // 99
    return 0;
}

Cảnh báo: Truy cập ngoài phạm vi (a[5], a[-1]) là lỗi nghiêm trọng (undefined behavior) — có thể đọc/ghi đè vùng nhớ khác, gây crash hoặc lỗi khó lần.

6.3. Các thao tác cơ bản trên mảng một chiều

6.3.1. Nhập mảng

int a[100], n;
cout << "Nhap so phan tu: ";
cin >> n;

for (int i = 0; i < n; i++) {
    cout << "a[" << i << "] = ";
    cin >> a[i];
}

6.3.2. Xuất mảng

for (int i = 0; i < n; i++) {
    cout << a[i] << " ";
}
cout << endl;

6.3.3. Tính tổng và trung bình

int sum = 0;
for (int i = 0; i < n; i++) sum += a[i];
double avg = (double)sum / n;

cout << "Tong = " << sum << endl;
cout << "Trung binh = " << avg << endl;

6.3.4. Tìm giá trị lớn nhất / nhỏ nhất

int maxVal = a[0], minVal = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] > maxVal) maxVal = a[i];
    if (a[i] < minVal) minVal = a[i];
}

Lưu ý: phải gán maxVal = a[0] (không phải 0) — vì mảng có thể toàn số âm.

6.3.5. Đếm phần tử thỏa điều kiện

int demChan = 0, demLe = 0;
for (int i = 0; i < n; i++) {
    if (a[i] % 2 == 0) demChan++;
    else               demLe++;
}

6.3.6. Đảo ngược mảng

for (int i = 0; i < n / 2; i++) {
    int tmp   = a[i];
    a[i]      = a[n - 1 - i];
    a[n - 1 - i] = tmp;
}

Hoặc dùng hàm có sẵn (C++11): reverse(a, a + n); — cần #include <algorithm>.

6.3.7. Kiểm tra mảng đối xứng (palindrome)

bool laDoiXung(int a[], int n) {
    for (int i = 0; i < n / 2; i++)
        if (a[i] != a[n - 1 - i]) return false;
    return true;
}

6.3.8. Xóa phần tử có giá trị x (dồn mảng)

void xoaX(int a[], int &n, int x) {
    int k = 0;
    for (int i = 0; i < n; i++)
        if (a[i] != x) a[k++] = a[i];
    n = k;
}

6.3.9. Chèn phần tử vào vị trí k

void chenTaiViTri(int a[], int &n, int k, int x) {
    for (int i = n; i > k; i--) a[i] = a[i - 1];
    a[k] = x;
    n++;
}

6.4. Truyền mảng vào hàm

6.4.1. Đặc điểm

Khi truyền mảng vào hàm, C++ không sao chép toàn bộ mảng mà truyền con trỏ đến phần tử đầu. Do đó:

  • Hàm có thể thay đổi trực tiếp nội dung mảng gốc.
  • Không cần (và không nên) dùng & cho mảng.
  • Phải truyền kích thước mảng riêng, vì hàm không biết mảng dài bao nhiêu.

6.4.2. Cú pháp

void tenHam(int a[], int n);         // cách phổ biến
void tenHam(int a[100], int n);      // số 100 bị bỏ qua, chỉ để dễ đọc
void tenHam(int *a, int n);          // tương đương

Nếu không muốn hàm thay đổi mảng: thêm const:

void inMang(const int a[], int n);   // chỉ đọc, không sửa

6.4.3. Ví dụ đầy đủ

#include <iostream>
using namespace std;

void nhapMang(int a[], int &n) {
    cout << "Nhap n: "; cin >> n;
    for (int i = 0; i < n; i++) {
        cout << "a[" << i << "] = ";
        cin >> a[i];
    }
}

void xuatMang(const int a[], int n) {
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    cout << endl;
}

int tinhTong(const int a[], int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}

int main() {
    int a[100], n;
    nhapMang(a, n);
    xuatMang(a, n);
    cout << "Tong = " << tinhTong(a, n) << endl;
    return 0;
}

Lưu ý quan trọng: Vì n cần được thay đổi bởi hàm nhapMang, ta truyền int &n (tham chiếu). Nhưng a[] luôn là con trỏ, không cần &.

6.5. Sắp xếp và tìm kiếm trên mảng

6.5.1. Sắp xếp nổi bọt (Bubble Sort)

Ý tưởng: Duyệt mảng nhiều lần; mỗi lần so sánh từng cặp phần tử kề nhau và đổi chỗ nếu sai thứ tự. Sau mỗi lượt, phần tử lớn nhất "nổi" về cuối mảng.

void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) {
                int tmp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = tmp;
            }
}

Độ phức tạp: O(n²) — chậm với mảng lớn nhưng dễ hiểu, thích hợp để học.

6.5.2. Sắp xếp chọn (Selection Sort)

Ý tưởng: Mỗi lượt, tìm phần tử nhỏ nhất trong phần chưa sắp xếp và đưa về đầu phần đó.

void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[minIdx]) minIdx = j;
        swap(a[i], a[minIdx]);   // cần #include <algorithm> hoặc viết tay
    }
}

Độ phức tạp: O(n²).

6.5.3. Sắp xếp chèn (Insertion Sort)

Ý tưởng: Duyệt từng phần tử, "chèn" nó vào đúng vị trí trong phần đã sắp xếp phía trước. Rất hiệu quả với mảng gần như đã sắp xếp.

void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}

6.5.4. Tìm kiếm tuyến tính (Linear Search)

Ý tưởng: Duyệt từ đầu đến cuối, so sánh từng phần tử với x.

int linearSearch(const int a[], int n, int x) {
    for (int i = 0; i < n; i++)
        if (a[i] == x) return i;
    return -1;   // không tìm thấy
}

Độ phức tạp: O(n). Áp dụng được cho mảng chưa sắp xếp.

6.5.5. Tìm kiếm nhị phân (Binary Search)

Ý tưởng: So sánh x với phần tử giữa. Nếu bằng → tìm thấy. Nếu x nhỏ hơn → tìm nửa trái. Nếu lớn hơn → tìm nửa phải. Mỗi lần loại bỏ một nửa.

Yêu cầu: mảng phải đã được sắp xếp tăng dần.

int binarySearch(const int a[], int n, int x) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) left = mid + 1;
        else            right = mid - 1;
    }
    return -1;
}

Độ phức tạp: O(log n) — nhanh hơn nhiều so với tìm tuyến tính khi mảng lớn.

So sánh:

+--------------------+-------------+----------------------+
|   Thuật toán       |  Độ phức tạp|  Yêu cầu mảng        |
+--------------------+-------------+----------------------+
|  Linear Search     |  O(n)       |  Không cần sắp xếp   |
|  Binary Search     |  O(log n)   |  Phải sắp xếp trước  |
+--------------------+-------------+----------------------+

6.6. Mảng hai chiều

6.6.1. Khái niệm

Mảng hai chiều là bảng dữ liệu dạng hàng × cột, thường dùng để biểu diễn ma trận, bảng điểm, bàn cờ, ảnh số, v.v.

6.6.2. Khai báo

kieu_du_lieu ten_mang[so_hang][so_cot];

Ví dụ:

int a[3][4];              // Ma trận 3 hàng × 4 cột (12 phần tử)
double diem[30][5];       // Bảng 30 sinh viên × 5 môn
char banCo[8][8];         // Bàn cờ vua

6.6.3. Khởi tạo

// Đầy đủ
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

// Một phần
int b[2][3] = {{1, 2}, {4}};    // = {{1,2,0}, {4,0,0}}

// Tất cả bằng 0
int c[3][3] = {0};

6.6.4. Truy cập phần tử

Cú pháp: ten_mang[i][j]; — với i là chỉ số hàng, j là chỉ số cột (cả hai bắt đầu từ 0).

a[0][0] = 10;                 // Gán phần tử hàng 0, cột 0
cout << a[1][2] << endl;      // Đọc phần tử hàng 1, cột 2

6.6.5. Nhập / Xuất ma trận

int a[100][100], m, n;
cout << "So hang, so cot: ";
cin >> m >> n;

// Nhập
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        cin >> a[i][j];

// Xuất
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++)
        cout << a[i][j] << " ";
    cout << endl;   // xuống dòng sau mỗi hàng
}

6.6.6. Một số bài toán tiêu biểu

Tính tổng toàn ma trận:

int tong = 0;
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        tong += a[i][j];

Tổng đường chéo chính (ma trận vuông cấp n):

int s = 0;
for (int i = 0; i < n; i++) s += a[i][i];

Tổng đường chéo phụ:

int s = 0;
for (int i = 0; i < n; i++) s += a[i][n - 1 - i];

Cộng hai ma trận cùng kích thước:

for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        C[i][j] = A[i][j] + B[i][j];

Nhân hai ma trận (A: m×n, B: n×p, C: m×p):

for (int i = 0; i < m; i++)
    for (int j = 0; j < p; j++) {
        C[i][j] = 0;
        for (int k = 0; k < n; k++)
            C[i][j] += A[i][k] * B[k][j];
    }

Chuyển vị ma trận (A: m×n → B: n×m, với B[j][i] = A[i][j]):

for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        B[j][i] = A[i][j];

6.7. Chuỗi ký tự kiểu C (C-string)

6.7.1. Khái niệm

C-string là một mảng ký tự kết thúc bằng ký tự đặc biệt '\0' (null character, mã ASCII = 0). Đây là kiểu chuỗi truyền thống của C, vẫn còn dùng rộng rãi trong C++.

6.7.2. Khai báo và khởi tạo

char s1[20];                        // Mảng 20 ký tự (rỗng)
char s2[20] = "Hello";              // "Hello" (tự động thêm '\0')
char s3[] = "Hello";                // Kích thước tự tính = 6 (5 ký tự + '\0')
char s4[6] = {'H','e','l','l','o','\0'};   // Cách tường minh

Lưu ý: "Hello" cần mảng ít nhất 6 ký tự (5 chữ + 1 ký tự kết thúc).

6.7.3. Nhập / Xuất

char s[100];
cin >> s;         // Đọc một từ (dừng ở khoảng trắng)
cin.getline(s, 100);   // Đọc cả dòng (bao gồm khoảng trắng)
cout << s << endl;

Lưu ý: cin >> s không đọc được chuỗi có khoảng trắng. Muốn đọc cả câu, dùng cin.getline(s, kich_thuoc);.

6.7.4. Các hàm xử lý chuỗi (thư viện <cstring>)

+---------------------+---------------------------------------------+
|  Hàm                |  Chức năng                                  |
+---------------------+---------------------------------------------+
|  strlen(s)          |  Trả về độ dài chuỗi (không tính '\0')      |
|  strcpy(dest, src)  |  Sao chép src sang dest                     |
|  strncpy(dest,src,n)|  Sao chép tối đa n ký tự                    |
|  strcat(dest, src)  |  Nối src vào cuối dest                      |
|  strncat(dest,src,n)|  Nối tối đa n ký tự                         |
|  strcmp(s1, s2)     |  So sánh chuỗi (<0, =0, >0)                 |
|  strchr(s, c)       |  Tìm ký tự c trong s                        |
|  strstr(s, sub)     |  Tìm chuỗi con sub trong s                  |
+---------------------+---------------------------------------------+

Ví dụ:

#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s1[100] = "Hello";
    char s2[] = "World";

    cout << strlen(s1) << endl;      // 5

    strcat(s1, " ");                 // s1 = "Hello "
    strcat(s1, s2);                  // s1 = "Hello World"
    cout << s1 << endl;

    if (strcmp("abc", "abd") < 0)
        cout << "abc dung truoc abd" << endl;
    return 0;
}

6.7.5. Duyệt chuỗi

char s[100] = "Hello";
int len = strlen(s);

// Đếm số nguyên âm
int dem = 0;
for (int i = 0; i < len; i++) {
    char c = tolower(s[i]);
    if (c=='a'||c=='e'||c=='i'||c=='o'||c=='u') dem++;
}
cout << "So nguyen am: " << dem << endl;

Cần #include <cctype> cho tolower, toupper, isdigit, isalpha, isspace.

6.8. Chuỗi std::string (khuyến nghị dùng)

6.8.1. Khái niệm

std::string là lớp chuỗi hiện đại của C++, an toàn và tiện lợi hơn C-string. Tự động quản lý bộ nhớ, hỗ trợ nhiều phép toán mạnh mẽ.

6.8.2. Khai báo và khởi tạo

#include <string>

string s1;                        // Chuỗi rỗng
string s2 = "Hello";
string s3("World");
string s4 = s2;                   // Sao chép
string s5(5, 'a');                // "aaaaa"
string s6 = s2 + " " + s3;        // "Hello World"

6.8.3. Nhập / Xuất

string s;
cin >> s;               // Đọc 1 từ
getline(cin, s);        // Đọc cả dòng
cout << s << endl;

Lưu ý: Nếu trước getline có cin >>, phải xóa bộ đệm bằng cin.ignore(); trước khi gọi getline.

6.8.4. Các thao tác phổ biến

+--------------------------+------------------------------------+
|  Thao tác                |  Ví dụ                             |
+--------------------------+------------------------------------+
|  Độ dài                  |  s.length() hoặc s.size()          |
|  Truy cập ký tự          |  s[i] (không kiểm tra biên)        |
|                          |  s.at(i) (có kiểm tra biên)        |
|  Nối chuỗi               |  s1 + s2, s1 += s2                 |
|  So sánh                 |  s1 == s2, s1 < s2, ...            |
|  Lấy chuỗi con           |  s.substr(pos, len)                |
|  Tìm chuỗi con           |  s.find(sub) → vị trí hoặc npos    |
|  Thay thế                |  s.replace(pos, len, newStr)       |
|  Chèn                    |  s.insert(pos, str)                |
|  Xóa                     |  s.erase(pos, len)                 |
|  Xóa toàn bộ             |  s.clear()                         |
|  Kiểm tra rỗng           |  s.empty()                         |
+--------------------------+------------------------------------+

Ví dụ:

#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "Hello World";

    cout << s.length() << endl;         // 11
    cout << s.substr(0, 5) << endl;     // "Hello"
    cout << s.find("World") << endl;    // 6

    s.replace(0, 5, "Hi");              // s = "Hi World"
    s += "!";                           // s = "Hi World!"
    cout << s << endl;
    return 0;
}

6.8.5. So sánh C-string và std::string

+--------------------------+----------------------+----------------------+
|  Tiêu chí                |  char[] (C-string)   |  std::string         |
+--------------------------+----------------------+----------------------+
|  Quản lý bộ nhớ          |  Tự làm              |  Tự động             |
|  Kích thước              |  Cố định             |  Động (tự mở rộng)   |
|  Nối chuỗi               |  strcat (nguy hiểm)  |  + , += (an toàn)    |
|  So sánh                 |  strcmp              |  ==, <, >           |
|  Độ dài                  |  strlen              |  .length()           |
|  An toàn                 |  Thấp (dễ tràn)      |  Cao                 |
|  Hiệu năng               |  Nhanh hơn chút      |  Chậm hơn chút       |
+--------------------------+----------------------+----------------------+

Khuyến nghị: Luôn ưu tiên std::string trừ khi có lý do đặc biệt (tương tác API C, tối ưu cực đoan).

6.9. Các lỗi thường gặp

  • Truy cập ngoài phạm vi mảng — a[n] khi mảng có n phần tử (hợp lệ là 0..n-1). Gây undefined behavior.
  • Khởi tạo mảng bằng biến thường — int a[n]; với n là biến không phải hằng → không chuẩn C++.
  • Quên kích thước mảng khi truyền vào hàm — hàm không thể biết mảng dài bao nhiêu nếu không truyền thêm n.
  • Quên dấu '\0' khi khởi tạo C-string — char s[5] = "Hello"; là lỗi (thiếu chỗ cho '\0').
  • Dùng cin >> s để đọc câu có khoảng trắng — chỉ đọc được 1 từ. Dùng getline.
  • Quên cin.ignore() trước getline khi trước đó có cin >> — ký tự newline còn sót trong bộ đệm khiến getline đọc dòng rỗng.
  • Gán mảng trực tiếp — a = b; cho hai mảng là lỗi. Phải sao chép từng phần tử hoặc dùng memcpy.
  • Nhầm strlen trả về số ký tự có thể chứa — nó trả về độ dài chuỗi thực tế, không phải kích thước mảng.
  • Sắp xếp nhầm hướng — if (a[j] > a[j+1]) sắp tăng; đảo dấu thành < để sắp giảm.
  • Quên reset sum = 0 khi tính tổng nhiều lần — giá trị cũ còn tích lũy.
  • Khởi tạo maxVal = 0 thay vì a[0] — sai khi mảng toàn số âm.
  • Truyền mảng 2D vào hàm chỉ ghi int a[][] — phải chỉ định số cột: int a[][100].

#include <iostream>

int main() {

Bài 16 — Tìm kiếm nhị phân:

#include <iostream>
#include <algorithm>
using namespace std;

int binarySearch(int a[], int n, int x) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x)  left = mid + 1;
        else             right = mid - 1;
    }
    return -1;
}

int main() {
    int a[] = {2, 4, 6, 8, 10, 12, 14};
    int n = 7, x = 10;
    int vt = binarySearch(a, n, x);
    if (vt != -1) cout << "Tim thay tai vi tri " << vt << endl;
    else          cout << "Khong tim thay" << endl;
    return 0;
}

#include <iostream>
using namespace std;

void nhanMaTran(int A[][100], int B[][100], int C[][100], int m, int n, int p) {
    for (int i = 0; i < m; i++)
        for (int j = 0; j < p; j++) {
            C[i][j] = 0;

}

    int B[100][100] = {{1, 2}, {3, 4}, {5, 6}};
    int C[100][100];

    nhanMaTran(A, B, C, m, n, p);

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < p; j++)
            cout << C[i][j] << " ";
        cout << endl;
    }
    return 0;
}

        l++; r--;

    return true;

#include <iostream>
#include <string>
#include <sstream>
#include <cctype>

string chuanHoa(string s) {
    stringstream ss(s);
    string word, result = "";
    while (ss >> word) {
        word[0] = toupper(word[0]);
        for (int i = 1; i < (int)word.length(); i++)
            word[i] = tolower(word[i]);
        if (!result.empty()) result += " ";
        result += word;
    }
    return result;
}

6.12. Tóm tắt chương

  • Mảng là tập hợp các phần tử cùng kiểu, lưu liên tiếp, truy cập qua chỉ số từ 0.
  • Kích thước mảng là hằng số khi khai báo. Không khởi tạo → phần tử có giá trị rác.
  • Khởi tạo một phần (int a[5] = {1,2};) → các phần tử còn lại = 0.
  • Truyền mảng vào hàm: truyền con trỏ, hàm có thể sửa mảng gốc — nhưng phải truyền kích thước riêng.
  • Bubble / Selection / Insertion Sort: O(n²), dễ hiểu, phù hợp học tập.
  • Linear Search: O(n), dùng cho mảng chưa sắp xếp.
  • Binary Search: O(log n), yêu cầu mảng đã sắp xếp.
  • Mảng hai chiều: a[m][n] — hàng × cột. Dùng cho ma trận, bảng điểm.
  • C-string: mảng char kết thúc '\0'. Hàm xử lý trong <cstring>.
  • std::string: an toàn, tiện lợi — khuyến nghị dùng thay C-string.
  • Luôn kiểm tra chỉ số hợp lệ (0 → n-1) trước khi truy cập mảng.
  • Khởi tạo maxVal = a[0] (không phải 0) để đúng khi mảng toàn âm.
  • Đọc câu có khoảng trắng: dùng getline(cin, s) với std::string, hoặc cin.getline(s, n) với C-string.
